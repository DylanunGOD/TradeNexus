# TradeNexus

Aplicación web responsive para publicar y vender cartas coleccionables (TCG) con trazabilidad por la red de tiendas afiliadas. Tienda ancla: Burro Singles.

> Proyecto académico · Administración de Proyectos

## Tecnologías

- Next.js 16 (App Router) + TypeScript + Tailwind CSS 4
- Supabase (PostgreSQL, Auth, Storage, Realtime)
- Vercel Hobby (hosting)

## Desarrollo local

```bash
npm install
cp .env.example .env.local   # llenar con los datos de Supabase
npm run dev
```

La guía técnica completa se completará al cierre del proyecto.
